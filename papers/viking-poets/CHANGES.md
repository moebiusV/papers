# Editorial pass — What the Viking Poets Knew

## 1. Em-dashes removed (~640 → 4)
Every prose em-dash was converted, following the style you had already
established by hand in `00_introduction_the_wrong_question.EDITED.md`:

- parenthetical pairs ( — X — )        → commas
- explanatory labels ( ... — the scroll ) → colon
- appositives / asides ( viral — over 16M ) → comma
- joins of two independent clauses     → semicolon (never a period-fragment)
- dash before a conjunction ( — but / — and ) → comma

The 4 remaining em-dashes are all intentional: three epigraph attribution
lines (— Taliesin / — Leviticus 16:13 / — Nebuchadnezzar II) and one
line-final dash inside the quoted Nebuchadnezzar inscription (verse).

This is a mechanical pass in your own voice. A handful of the new commas
would read better as colons or periods; those are judgment calls left for
your final read (see the note in the chat).

  actual bounded-precision Turing-completeness result. Verify this substitution
