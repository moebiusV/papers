# Plates

Images referenced from `book.typ` via `#plate()` and `#inline-plate()`.

## Formats

Typst reads PNG, JPEG, GIF, and SVG. Prefer **SVG** for anything line-based
(dragon curve, Koch snowflake, Sierpiński gasket): it stays sharp at any size
and the files are tiny. Use **PNG** for escape-time renders (Mandelbrot, Julia
sets) and for the fern's point cloud.

For print, raster art should be ~300 dpi at final printed size. On the current
5.5 x 8.5 in trim with 0.75 in margins that means roughly:

| Use | Printed size | Pixels |
|---|---|---|
| Full-page plate | 4.0 x 6.0 in | 1200 x 1800 |
| Full-bleed plate | 5.5 x 8.5 in | 1650 x 2550 |
| Inline figure at 70% | 2.8 in wide | 850 wide |

## Generate, don't source

Every figure the book needs is generated by a short program, so render them
rather than finding them. A rendered Mandelbrot set or Barnsley fern is an
original work with no rights attached; a found one almost always has an author
and a licence, and colour-plate sections are exactly where rights problems
surface late and expensively.

## Usage

```typst
#plate("plates/fern.png")[Barnsley's fern.][Four affine maps, each scaling
  and rotating, iterated to a fixed point.]

#inline-plate("plates/dragon.svg", 70%)[The Heighway dragon.]
```

`#plate()` breaks to the next recto, suppresses header, footer, and folio,
centres the image on the page, and sets the title in italic with an optional
caption beneath. `#inline-plate()` sets a numbered figure in the text column.
